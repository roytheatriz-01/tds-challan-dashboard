# TDS Challan Register

Company-wise and section-wise register of TDS challans (ITNS 281) with uploaded challan copies, month-wise due-date status and CSV export.

Live version (with saved data and file uploads): https://claude.ai/artifact/KDmk5eatkjrho5CtFo7iiS

Note: `index.html` uses claude.ai artifact capabilities (database, file storage, downloads). Opened outside claude.ai it shows the layout only and cannot save or upload challans.
